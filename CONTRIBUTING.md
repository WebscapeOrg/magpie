# Contributing to Magpie

Magpie is Dave's fork of [Omamail](https://github.com/huacnlee/omamail), and the agents on his machine make
its changes. Read [MAGPIE.md](MAGPIE.md) for what Magpie is and how it is installed, and [AGENTS.md](AGENTS.md) for the
rules agents follow here.

Each change goes on its own branch with a draft pull request in WebscapeOrg/magpie. Omamail's contributor guide,
including its review, screenshot and release rules, does not apply to Magpie. Whether a change also goes to Omamail is
Dave's decision; agents ask him through Pickle, and such a change then follows huacnlee/omamail's own guide.

Do not open a public issue or pull request about a security problem; tell Dave privately first.
