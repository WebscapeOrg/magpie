# Lucide icons

[Lucide 1.58.0](https://github.com/lucide-icons/lucide/tree/7b0196e249ca09ca27c584c497aca9a8cab8a7f5) supplies the SVG geometry in [Icons.js](../../components/Icons.js). The `LUCIDE` map names each upstream icon; `ARTWORK` retains its drawing elements and coordinates. The renderer uses the original 24-unit view box, two-unit stroke, rounded caps and joins, and applies the active theme color. A selected star fills the same outline.

The source revision is `7b0196e249ca09ca27c584c497aca9a8cab8a7f5`. The accompanying [license](LICENSE) retains Lucide’s ISC notice and the MIT notice for icons derived from Feather. These bundled drawings require no network requests, icon font or JavaScript package at runtime.
